MM2 SHOP — защищённые заказы

Теперь заказы НЕ хранятся в localStorage посетителя.
Сайт отправляет заказ на server.js, а сервер сохраняет его в data/orders.json.
Посетители не могут получить список заказов без админ-пароля.

Запуск:
1. Установи Node.js.
2. Открой эту папку в терминале.
3. Windows PowerShell:
   $env:ADMIN_PASSWORD="ТВОЙ_СЕКРЕТНЫЙ_ПАРОЛЬ"
   node server.js
4. Открой магазин: http://localhost:3000
5. Админка: http://localhost:3000/admin

ВАЖНО:
- Для настоящего публичного сайта сервер должен быть размещён на хостинге/VPS, а не только открыт как index.html.
- Пароль не хранится в HTML и задаётся через переменную окружения.
- Для HTTPS на публичном сайте используй HTTPS/прокси хостинга.
